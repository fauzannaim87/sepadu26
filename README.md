# Data Guru Kedah: app skrin utama

Halaman pelancar untuk Dashboard Data Sepadu Guru JPN Kedah, supaya dashboard boleh dipasang
sebagai ikon di skrin utama telefon Android dan iPhone.

1. Dalam `index.html`, tukar `GAS_URL` kepada URL Web App (.exec) dashboard.
2. Muat naik semua fail dan folder `icons` ke repo GitHub, kemudian aktifkan GitHub Pages.
3. Kongsi pautan GitHub Pages kepada pengguna. Mereka buka pautan itu dan tambah ke skrin utama.

Fail: `index.html` (pelancar), `manifest.webmanifest` (maklumat app Android),
`sw.js` (pembukaan pantas), `icons/` (ikon semua saiz).
